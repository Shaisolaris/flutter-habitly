# Habitly — Habit Tracker App

Habit-tracking mobile app presented in an interactive phone frame.

**[Live Demo](https://shaisolaris.github.io/flutter-habitly/)**

## Features

- **Today view** — daily check-ins with an animated SVG progress ring, per-habit streaks that increment on completion with milestone celebrations
- **Stats** — best streak, completion rate, 28-day consistency heatmap, per-habit completion bars
- **Habit creation** — name, icon picker, frequency selector; new habits land in the Today list immediately
- **Phone-frame presentation** — pitch panel plus a 390×812 device shell with status bar, notch, and tab bar

## Structure

Single self-contained page: Flutter-style mobile UI patterns (bottom tabs, cards, ring progress) implemented in pure HTML/CSS/JS. No frameworks, no build step.
